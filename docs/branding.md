# Logo kaynağı

Kullanıcının paylaştığı Kocaeli Üniversitesi amblemi referans alınmıştır. Sohbet görselinin yerel dosyası erişilebilir olmadığından aynı amblemin e-Devlet kurum sayfasındaki sürümü indirilmiştir.

- Kurum sayfası: https://www.turkiye.gov.tr/kocaeli-universitesi
- Dosya kaynağı: https://cdn.e-devlet.gov.tr/themes/ankara/images/logos/64webp/1301.1.8.0.webp
- Yerel dosya: `apps/client/public/kou-logo.webp`
- Kaynak görsel 64 piksel olduğundan arayüzde 48 piksel kullanılır.

Arayüz renkleri önceki geçici palettir; resmî marka renkleri olarak doğrulanmamıştır.
